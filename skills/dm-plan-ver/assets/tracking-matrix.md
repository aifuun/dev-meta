# 📋 版本 TF 追踪矩阵

> 用于追踪版本内各 TF 从 Issue 创建到合并、验收的完整状态。

## 追踪矩阵

| TF | Issue | PR | 验收 |
|----|-------|-----|------|
| TF1 | #xx | #xx | ⬜ |
| TF2 | #xx | #xx | ⬜ |
| TF3 | #xx | #xx | ⬜ |

> 状态：⬜ 未开始 / 🔄 开发中 / ✅ 已完成 / ❌ 已取消

## 使用规则

1. **版本创建时**：为每个 TF 生成 Issue（标题 `[TFx] <flow-name>`），关联到版本 PR，填入矩阵首行。
2. **TF 完成时**：确认验收标准 → 建议 commit → 更新矩阵 TF 状态为 ✅ → 建议关闭对应 Issue。
3. **版本关闭时**：检查全部 TF 已关闭、矩阵全 ✅，再输出 merge 建议。

## §5 DoD 核对（合并前）

- [ ] **无裸露日志**：关键路径全部经 `observe(...)` 包装，不散落原始 `print` / `console.log`。
- [ ] **写逻辑即写观测**：关键节点同步注入结构化日志 + 出口 Assert，逻辑与观测不可分离提交。
- [ ] **无静默吞错**：所有 `try-catch` / 降级分支均有诊断快照留痕。
- [ ] **高开销节点覆盖**：I/O / 网络 / 推理 / 跨进程均含 `Elapsed Time` + 资源指标。
- [ ] **Log-Driven 排查**：报错时只贴结构化日志 / Crash / Trace，不向 AI 描述自然语言现象。
- [ ] **验证闭环**：构造坏数据时能输出可解析的诊断上下文，复制给 AI 后可一次定位。

> DoD 唯一权威为 dev-meta 07 §7；本清单为项目侧核对副本，如有差异以 07 为准。

## 3. 迁移策略

### 3.1 本地 / 客户端存储

```
Schema 变更流程：
  1. 递增版本号
  2. 启动时检测 → 执行幂等迁移函数
  3. 迁移完成后更新版本号

回滚策略：
  - 新增字段给默认值，不删旧字段（标记 @deprecated）
```

### 3.2 服务端 / 数据库

```
Schema 变更流程：
  1. 先加字段（nullable, default value）
  2. 上线验证兼容性
  3. 再移除废弃字段（不在一个版本内同时加减）

回滚策略：
  - 新字段保持 nullable，回滚时忽略即可
```

### 3.3 配置表 / 静态数据

```
- 随版本发布，客户端校验版本号
- 新版本向后兼容（新增字段给默认值）
```

# MDX 示例

MDX 里可以直接写 JSX，由 Astro 在构建时编译：

<div style={{ padding: "1rem", border: "1px solid #d0d7de", borderRadius: 8 }}>
  这是 <strong>MDX</strong> 片段，用于验证 MDX 集成是否生效。
</div>

## 与普通 Markdown 的区别

- `.md` —— 纯 Markdown
- `.mdx` —— Markdown + JSX 组件
- `.html` —— HTML 片段，直接嵌入

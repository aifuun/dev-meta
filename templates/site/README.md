# 站点脚手架（由 `dm-pub-site` 实例化）

`content/` 是**内容的家**——放进去的 `.md` / `.mdx` / `.html` 都会出现在目录树索引里。
本目录其余部分是脚手架，通常不需要改动。

## 硬规则

- **内容源唯一**：只往 `content/` 写，不从项目其它目录复制（避免同一内容多份副本）。
- **索引是派生物**：首页目录树与各页面路由均由构建生成，**禁止手工编辑 `dist/`**（每次构建覆盖）。
- **发布前必须生成 `.nojekyll`**：GitHub Pages 默认跑 Jekyll，会忽略下划线目录（Astro 产物含 `_astro/`），
  缺此文件会导致样式与脚本全 404 且不报错。

## 常用命令

```bash
npm install
npm run dev      # 本地预览
npm run build    # 产出 dist/
```

## `.html` 的处理

- HTML **片段**（无 `<html>` 包裹）→ 直接嵌入站内渲染，共享导航与样式。
- HTML **完整文档**（含 `<html>`）→ 只抽取 `<body>` 内容嵌入；`<head>` 会被丢弃。
  若需原样发布完整文档，请改写为 `.md` / `.mdx`，或放入 `public/`。
